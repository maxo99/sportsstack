# SportsStack


## Components

### API Gateway

- Spring Cloud Gateway for routing and load balancing.
- resilience4j for circuit breaking and rate limiting.
- Aggregate swagger docs at [swagger-ui](http://localhost:8088/swagger-ui/index.html)
